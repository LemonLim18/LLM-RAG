### Narrow release validation and its limits

Checks detect missing/duplicate/unknown obligation IDs, unknown evidence/relationship references, incorrect declared reference binding, exact scalar contradiction and recorded/modeled/physical authority mismatch. Existing S-labels resolve to their actual receipts; legitimate labels are not falsely rejected. Declared ownership, VRF, direction-specific disposition and explicit application values can therefore be compared against exact indexed facts.

Missing entries produce a **model omission**, including the actual evidence-availability state; they do not become a source-unavailable claim or a new retrieval request. Unresolved entries count as present. Unsupported established declarations lacking citations get an explicit limitation. Invalid core bindings are withheld. Actual declared contradictions reuse the existing bounded sentence/whole-interpretation withholding policy. Raw answers and original proposals remain in traces. Valid qualified prose is preserved in positive tests. No automatic revision, supplementary read or second critic is triggered by this adapter.

Important limitations: a conclusion can contain wrong causal prose despite all declared scalars matching. The model may omit a material assertion from `assertions`, cite a correct fact for an invalid inference, or leave part of a compound noun phrase unanswered inside a populated obligation. The adapter does not certify those cases. Whole-answer withholding for a contradiction that cannot be isolated may suppress otherwise valid text; actual false-suppression frequency requires live grading. An unverified label alone never earns adequacy credit.
