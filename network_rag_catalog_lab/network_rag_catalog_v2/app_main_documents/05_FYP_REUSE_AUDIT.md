# Iteration 0 — FYP Selective Reuse Audit

Status: completed source audit, 2026-10-08. Classification is a design recommendation, not a claim that extracted code has been built or tested. No application code was changed or executed.

## Scope and evidence

The inspected prototype exists at `app_main_documents/Net_Topo_View-intentparse/` relative to the V9 project root. All links below identify actual source files relative to this document. Inspection followed the application entry point, its component imports, relevant inventory/editor/topology views, and their backend dependencies. Historical planning instructions were not executed.

**REUSE** means minor adaptation; **ADAPT** means substantial extraction or changes; **REPLACE** means a new implementation better serves the requirement; **DISCARD** means excluded from the new workbench. Discarding is a reuse decision only: the historical files remain intact.

## Dependency and maintainability conclusions

The inspected [frontend manifest](Net_Topo_View-intentparse/frontend/package.json) declares React 19.2, Vite 7.2, TypeScript 5.9 and `@monaco-editor/react` 4.7 ranges, plus Google AI SDKs, xterm, D3, two React Cytoscape wrappers, charts, Markdown, Tailwind/DaisyUI, SweetAlert and UUID. These are observed declarations, not verified installed or compatible versions. Do not copy the dependency list. The [TypeScript configuration](Net_Topo_View-intentparse/frontend/tsconfig.app.json) enables strict checks, but large views and the facade still use `any`; frontend code is split among `src`, root-level views/components/contexts and services.

The [backend requirements](Net_Topo_View-intentparse/backend/requirements.txt) mix FastAPI with device connectivity, NetBox, Ansible, scheduling, Redis, InfluxDB and document/AI packages, many without version pins. No package installation, dependency vulnerability scan, build or dependency compatibility certification was performed.

Frontend manifest scripts include dev/build/lint/preview, but no test script. A scoped frontend filename search found no test/spec files. Backend tests exist; their mere existence does not establish safe isolation: [test_netbox_update.py](Net_Topo_View-intentparse/backend/tests/netbox/test_netbox_update.py) performs a NetBox device update at module level. Do not run the prototype test tree wholesale during a later audit or shell iteration.

## Concrete reuse recommendation

Iteration 1 should build a new small `frontend/` at the V9 root. Reuse the callback-driven ChatInput and static device icon artwork with the minor changes above. Adapt only layout proportions, Monaco options and tab visual patterns from AnsibleStudioView/PlaybookEditor. Build explorer, state, mock chat, output panel, splitters and editor ownership for the new model. No FYP backend, old session controller, runtime model selector, intent logic, execution controls, topology dependencies or database schema is needed for that deliverable.

The integration contracts, persistence choices, remaining implementation checks and exact next-iteration scope are in [06_GUI_INTEGRATION_DESIGN.md](06_GUI_INTEGRATION_DESIGN.md).
