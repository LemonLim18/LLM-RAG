# OSPF

OSPF is a link-state routing protocol.

## OSPF Basics

OSPF routers exchange link-state information.

### Link-State Database

Each router maintains a Link-State Database (LSDB).

### SPF Algorithm

OSPF uses the SPF algorithm to calculate the shortest path.

## OSPF Troubleshooting

Common OSPF problems include neighbor failures.

### Neighbor Issues

Check whether the neighbor state reaches FULL.

### MTU Mismatch

An MTU mismatch can cause routers to become stuck in EXSTART.

# BGP

BGP is a path-vector routing protocol.

## BGP Basics

BGP exchanges routing information between autonomous systems.

### Autonomous System Numbers

BGP uses AS numbers to identify autonomous systems.
